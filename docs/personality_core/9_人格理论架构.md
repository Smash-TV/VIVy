# 澄音人格理论架构 v1.0

> 日期：2026-08-20
> 状态：理论归并结案版；作为后续人格模型工程设计的理论基线
> 依据：`7_理论变量归并表.md` 的 A—R 取舍结论与 `1_总体架构.md`—`6_世界模型.md` 的详细研究

## 0. 文档定位

本文把此前分散在六套人格心理学流派、世界模型、记忆和工程选型文档中的已确定结论，整理成一份可以直接用于下一阶段设计的统一理论架构。

本文确定的是：

- 人格内核需要保存和计算哪些心理对象；
- 每个对象由哪个理论提供语义；
- 世界模型、人格、记忆、知识图谱和表达层分别拥有什么写权限；
- 哪些理论只作外部评估、历史解释或已经删除；
- 一次互动中各部分怎样协作。

本文暂不确定：

- CAPS 内部最终使用公式、规则网络、神经网络、潜空间还是混合方案；
- 各变量的最终数值、阈值、衰减率和学习率；
- Prompt、LoRA、人格向量或模型权重如何承载静态人设；
- llm-wiki 知识图谱是否保存人格学习证据以及如何引用；
- 具体代码类、配置 Schema 和数据库表。

因此，v1.0 表示理论归属与边界已经闭合，不表示工程实现已经完成。

## 1. 核心结论

澄音的人格不由某一个总分、Prompt、LoRA 或单一心理学流派承载。当前架构采用：

> 世界模型负责形成可追溯的感知，统一 `PersonalityState` 保存人格状态，CAPS 负责情境化运行，互动记忆提供经历证据，LLM 负责语义理解与最终表达。

六套理论不会分别运行六遍，也不建立六层人格引擎。保留下来的概念必须进入同一套 CAPS 计算语法；没有独立机制价值的理论只保留出处，不复制状态。

## 2. 总体结构

```text
现实输入：文本 / 语音 / 图像 / 时间 / 设备环境
                         ↓
世界模型 perceive()
观察事实 + 推测 + 不确定性 + 按需 Kelly 建构解释
                         ↓
相关互动记忆检索 + 已确定身份事实检索
                         ↓
按需调用规划
普通轮次直接通过；明确脆弱/求助/危险时可调用外部照料 Skill
                         ↓
┌──────────────────── CAPS 人格内核 ────────────────────┐
│ 编码 │ 预期与信念 │ 情感 │ 目标与价值 │ 能力与调节计划 │
│                                                        │
│ 当前自我表示、依恋、EAS、情绪内核与情境在此相互作用   │
│                  形成 if-then 行为倾向                 │
└────────────────────────────────────────────────────────┘
                         ↓
人格结果：状态变化 + 行动倾向 + 表达约束 + 可追溯依据
                         ↓
LLM / 动作 / 表情 / TTS
                         ↓
互动事件写入记忆；长期学习候选走离线或定时更新
```

这是一条逻辑管线，不表示每一步都要单独调用一个 LLM。确定性读取和低维状态更新优先用普通算法；语义理解与最终语言才使用模型。调用规划器可以跳过本轮不需要的 Kelly 解释、外部照料能力、复杂记忆检索或离线学习。

## 3. 唯一人格状态的概念结构

项目只设计一份 `PersonalityState`。时间尺度是字段属性，不拆成快、中、慢三套状态库，也不建立“管理器套管理器”。

```text
PersonalityState
├─ affect
│  ├─ valence / arousal                 唯一连续情绪内核
│  ├─ baseline / decay                  基线与回落属性
│  └─ intensity / sensitivity / expressivity
├─ temperament_eas
│  └─ emotionality / activity / sociability
├─ attachment
│  └─ anxiety / avoidance               两个连续维度
├─ self_representations[]
│  └─ current / hoped / feared          一类记录、三种语义
└─ caps
   ├─ encodings
   ├─ expectancies_and_beliefs
   ├─ goals_and_values
   ├─ competencies_and_regulatory_plans
   └─ if_then_signatures
```

以下内容只在本轮派生，不持久化第二份状态：

- 工作自我概念：当前被激活的自我表示子集；
- 安全型、专注型、冷漠型、恐惧型依恋标签；
- 愤怒、悲伤、恐惧、喜悦等具体情绪名称；
- `empathy_intensity`、`attention_hint` 和本轮策略选择；
- 外部照料 Skill 返回的建议；
- 大五、Bem、马斯洛等外部评估结果：可以另存只读报告，但不持久化到 `PersonalityState`。

## 4. 六套理论如何统一

### 4.1 认知流派：感知解释、自我表示与运行框架

| 理论 | 保留内容 | 工程归属 | 明确边界 |
|---|---|---|---|
| Kelly 个人建构 | 用双极区分解释人物和事件 | 世界模型的按需推测步骤 | 不采用 RepGrid、建构图、关联网络或全局通透性分数；观察与解释分开 |
| Markus 自我研究 | 当前自我图式、可能自我、工作自我概念 | `self_representations` 与本轮激活结果 | 不能包揽身份事实、事件、对用户的预期、目标或价值 |
| Mischel & Shoda CAPS | 五类认知—情感单元和 if-then 行为签名 | 人格主运行框架 | 是项目统一计算语法，不宣称为学界统一人格理论 |

#### Markus 自我表示边界

- `current`：只保存由重复经验或稳定人设证据组织起来、领域明确、对自我重要且能支持同领域判断或预测的当前自我图式；
- `hoped` / `feared`：保存希望或害怕成为的可能自我，不冒充当前图式；
- 工作自我概念：本轮激活子集，不持久化；
- 临时自我评价留在本轮推断或互动记忆，允许某个领域没有图式；
- 经验开放是当前自我图式接纳反证的更新原则，不是人格分数。

### 4.2 精神分析流派：只保留依恋的可操作机制

#### 依恋内核

依恋焦虑和依恋回避是两个权威连续维度。四种成人依恋类型只是二维空间的派生解释：

| 焦虑 | 回避 | 派生类型 |
|---|---|---|
| 低 | 低 | 安全型 |
| 较高 | 较低 | 专注型 |
| 较低 | 较高 | 冷漠型 |
| 较高 | 较高 | 恐惧型 |

四型不分别保存参数，不单独校准，也不绕过焦虑/回避直接驱动行为。具体高低边界由后续评测确定。

内部工作模型不再保存为第三份 `working_model`：

- “我在关系冲突中通常会退缩”这类依恋来源的自我概括，满足 Markus 门槛后进入关系领域 `current` 自我图式；
- “这个用户是否可靠、会不会回应”进入 CAPS 的预期与信念；
- 原始关系事件进入互动记忆；
- 焦虑/回避作为慢变量保留。

#### 依恋照料系统

照料系统外移为触发式插件或 Skill，不作为常驻人格倾向。世界模型提供明确求助、脆弱或危险线索，调用规划器决定是否启用；外部能力只返回照料/保护建议，CAPS 根据澄音自己的价值、关系、能力、情绪和边界决定是否采纳。

#### 其余取舍

- 弗洛伊德本我—自我—超我与独立防御模块删除；
- 阿德勒只作历史解释，不提供运行变量；
- 埃里克森阶段删除，AI 年龄只由 `born_at` 计算；
- “亲密—孤独”只可作非阶段外部关系评估。

### 4.3 特质流派：连续情绪内核与外部评估

Russell 效价—唤醒坐标是唯一可写的连续情绪内核：

- `valence` 表示愉快—不愉快；
- `arousal` 表示激活—低激活；
- 坐标保存连续底色，不独自解释情绪对象、原因和行动；
- 愤怒与恐惧可能同属负效价、高唤醒，必须结合威胁、责任归属、可控性和对象区分；
- PA/NA 只作外部分析或即时换算，PAD 不进入运行时；
- 离散情绪和 TTS 标签只能从内核派生，不能反向覆盖连续状态。

情绪强度、正负敏感性和表达性分别保留：

| 概念 | 负责什么 | 不负责什么 |
|---|---|---|
| 情绪强度 | 激活后的总体体验振幅 | 不决定正负方向，不等于外部表达 |
| 积极/消极敏感性 | 不同效价方向输入的响应增益 | 不等于当前情绪坐标 |
| 情绪表达性 | 内部状态表现到语言、动作和语音的程度 | 不能伪造内部状态或立场 |

大五 OCEAN 只作外部评估，不进入内核，也不得反向驱动情绪、行为、提示词或学习。其他宽泛特质体系不进入当前架构。

### 4.4 生物学流派：EAS 气质

保留 Buss 与 Plomin 的三个 EAS 气质变量：

- 情绪性：稳定的负性情绪反应倾向；
- 活动性：稳定的基础能量与活动水平；
- 社交性：偏好与他人相处和发起接触的倾向。

三者只共享理论来源，不合成气质总分，也不互相代替。它们不等于当前动机、依恋安全、情绪强度、敏感性或大五投影。PEN 整体退出人格架构。

### 4.5 人本主义流派：关系原则而非完美女性模板

马斯洛整套理论只作外部评估，不建立需要层次和自我实现驱动力。

罗杰斯理论只保留四项可操作关系原则：

- 经验开放：当前自我图式允许反证进入评估；
- 一致性/真诚：表达可以克制、延迟或保留隐私，但不得为了迎合而伪造相反立场；
- 共情理解：输入理解形成可修正的用户视角假设，CAPS 按情境派生本轮共情力度；共情不等于赞同或服从；
- 用户指向 AI 的稳定接纳：作为关系安全证据，不要求澄音对用户无条件积极关注。

“机能充分发挥的人”和罗杰斯实现倾向均删除。澄音可以温柔，也可以生气、拒绝、失望、不同意或设立边界；人格架构不能把她训练成永远正确、永远舒适的服务型角色。

### 4.6 行为主义与社会学习流派：情境规律、效能与更新证据

- 班杜拉领域自我效能进入 CAPS“能力与调节计划”，表示“我在这个领域能否做到”；
- 自我调节计划与自我效能共用 CAPS 单元，但保持不同字段和证据；
- CAPS if-then 行为签名是唯一条件行为组织机制；
- 强化结果只作为更新证据，不建立强化状态或独立行为主义习惯；
- 特质激活只作理论来源标签，不建立运行权重；
- Bem 工具性/表达性只作外部评估，不成为性别角色控制器。

## 5. CAPS 内核的权威职责

| CAPS 单元 | 当前权威内容 | 主要输出 |
|---|---|---|
| 编码 | 感知结果、工作自我概念、关系线索、用户视角假设 | “这件事对澄音意味着什么”的情境编码 |
| 预期与信念 | 对用户和行为后果的预期、关系安全/被接纳预期 | 可能结果及其主观置信度 |
| 情感 | 效价—唤醒内核及情绪强度、敏感性参数 | 情绪状态增量和情绪意义候选 |
| 目标与价值 | 当前目标、关系目标、价值与边界 | 值得趋近、维持或避免的结果 |
| 能力与调节计划 | 领域能力、自我效能、v0 调节策略、自动应对倾向 | 能否行动、如何调节与采取什么策略 |
| if-then 行为签名 | 相似心理情境中的稳定条件规律 | 行动、互动和表达倾向 |

CAPS 不存原始经历，不生成最终自然语言，也不拥有身份事实。它读取本轮必要信息并输出结构化人格结果。

## 6. 一次互动的 v1.0 运行逻辑

### 6.1 感知与按需调用

1. 世界模型把输入拟合为统一 `PerceptState`；
2. 观察事实、推测和未知信息保持分离；
3. 只有确有解释价值时才应用 Kelly 双极建构；
4. 只检索当前情境所需的少量互动记忆；
5. 只有明确求助、脆弱或安全威胁时，规划器才考虑调用外部照料 Skill。

### 6.2 人格激活

1. 从 `self_representations` 派生本轮工作自我概念；
2. 从焦虑/回避坐标按需派生依恋类型标签；
3. CAPS 激活相关预期、情绪、目标、价值、能力与行为签名；
4. 事件评价产生效价和唤醒增量候选；
5. 情绪强度、正负敏感性和 EAS 情绪性共同影响情绪状态变化；EAS 活动性与社交性分别参与其他行为倾向，不强行并入情绪公式；
6. CAPS 形成行动与表达倾向，最终算法形式留待原型比较。

### 6.3 感知—调节闭环 v0

第一版暂定四种策略：

| 策略 | 作用对象 | 最小边界 |
|---|---|---|
| `reappraise` | 对事件意义的解释 | 只能在存在其他有证据的理解时使用，不得改写事实或否认伤害 |
| `modify_situation` | 可改变的互动或任务条件 | 可澄清、协商、调整和解决问题，不操控用户 |
| `redirect_attention` | 下一时刻的注意焦点 | 可暂时离开反刍，不得回避安全问题、事实义务或关系边界 |
| `pause_or_set_boundary` | 行动和接触强度 | 可防止冲突升级，不把沉默当作惩罚 |

闭环如下：

```text
世界模型形成 PerceptState(t)
          ↓
CAPS 根据情绪、目标、价值、关系与能力选择策略
          ↓
redirect_attention → 生成下一轮 attention_hint
其他策略 → 形成对外行动或内部解释调整
          ↓
世界模型在 t+1 感知实际结果
          ↓
结果写入互动记忆，长期更新另走审慎学习路径
```

这条边界是 v0 的正式初定版本：

- 世界模型可以执行 `attention_hint`，但不能决定“什么值得逃避”；
- 世界模型可以观察策略结果，但不能因为澄音想舒服一点就改写事实；
- 重评、暂停、设立边界和是否继续互动包含价值与关系立场，必须由 CAPS 决定；
- 四种策略进入原型评测，只有出现可复现的覆盖缺口时才扩充或调整。

### 6.4 表达与写回

- LLM 根据人格结果组织自然语言，不自行发明人格状态；
- 表达层可以调节措辞、动作和 TTS 强度，但必须遵守真诚边界；
- 具体情绪标签由连续内核和情境派生；
- 本轮事件与结果写入互动记忆；普通单轮输出不能直接成为自我图式或慢变量。

## 7. 与其他系统的数据所有权

| 系统 | 拥有的数据 | 不得拥有或直接改写的内容 |
|---|---|---|
| 世界模型 | 当前观察、推测、不确定性、按需 Kelly 解释 | 价值判断、关系立场、调节偏好、人格长期状态 |
| 互动记忆 | 交互事件、来源、时间、上下文及结果 | 人格权威结论、外部评估分数 |
| 知识图谱 | `born_at`、角色身世、实体与人物关系等已确定事实 | 人格证据接口尚未研究，不预设事件/证据 Schema |
| `PersonalityState` | 权威人格状态、参数和低维摘要估计 | 原始对话全文、完整事件历史、外部评估报告 |
| CAPS | 当前人格计算与行为倾向 | 身份事实原文、原始记忆、最终自然语言 |
| 表达层 | 语言、动作、表情和 TTS 映射 | 反向改写情绪内核、价值和自我图式 |
| 外部评估 | 大五、Bem、马斯洛及非阶段关系报告 | 任何回写人格、提示词、情绪或长期学习的路径 |

知识图谱是否承担人格证据、`evidence_refs` 如何兼容 llm-wiki URI，以及慢变量更新算法，已作为 O 存档到 `8_存档问题.md`，不阻塞 v1.0。

## 9. 已定理论与待定工程的分界

### 9.1 已经确定

- CAPS 是人格主运行框架；
- 世界模型负责感知拟合，Kelly 解释归世界模型且不使用建构图；
- Markus 自我表示的范围与一类记录原则；
- Russell 效价—唤醒是连续情绪内核；
- EAS 三维、情绪强度、正负敏感性和表达性分别保留；
- 依恋焦虑/回避是连续状态，四型按需派生；
- 依恋来源的自我概括可以进入领域自我图式，不保存 IWM 第三份状态；
- 照料系统外移为触发式插件或 Skill；
- v0 四种调节策略及感知—调节职责边界；
- 外部评估与删除项的单向边界；
