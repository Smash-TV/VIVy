# 1. 总体架构：以 CAPS 为人格运行框架

## 1.1 定位

CAPS 是澄音人格计算的**主要运行框架**：它提供统一的认知—情感单元和情境化 `if-then` 行为签名，用来组织最终保留的理论变量。

CAPS 不是学界已经融合全部人格流派的“人格统一理论”。本项目采用它，是因为它能把情境、主观解释、情绪、预期、目标、价值和调节能力放进同一次人格计算，而不是让六套理论各跑一遍。

```text
现实输入
   ↓
世界模型：发生了什么（PerceptState + 证据 + Kelly 建构解释 + 不确定性）
   ↓
记忆检索：哪些过去经验与当前情境有关
   ↓
┌──────────────────── CAPS 人格内核 ────────────────────┐
│ 编码 │ 预期与信念 │ 情感 │ 目标与价值 │ 能力与自我调节 │
│                    相互激活与约束                      │
│                if-then 行为签名                        │
└────────────────────────────────────────────────────────┘
   ↓
人格结果：内部状态变化 + 行为/表达倾向 + 解释依据
   ↓
LLM 与表达系统：组织语言、动作和语音
   ↓
事件写入互动记忆；必要时离线更新慢变量
```

## 1.2 其他理论如何进入 CAPS

六个流派不再对应六层或六个模块。通过归并后仍有独立用途的概念，才映射到 CAPS：

| CAPS 位置 | 可吸收的候选概念 | 边界 |
|---|---|---|
| 编码 | Markus 当前自我图式、工作自我概念、关系线索与用户视角假设 | Kelly 建构解释已经外移到世界模型；CAPS 编码读取感知结果并处理“这对澄音意味着什么”。对用户内在体验的推断必须携带不确定性 |
| 预期与信念 | 依恋维度、强化形成的结果预期、由长期互动形成的关系安全/被接纳预期 | 内部工作模型不另存状态：关系自我概括进入领域自我图式，对用户的预期留在本单元；用户对 AI 的稳定接纳属于关系证据，不是 KG 事实 |
| 情感 | Russell 效价—唤醒连续情绪内核、情绪敏感性与强度 | 只维护一份可写连续状态；具体情绪、PA/NA、PAD 与 TTS 标签只能按需派生或外部分析，不得并行更新 |
| 目标与价值 | 当前动机、关系目标、Markus 可能自我提供的未来方向、价值约束 | 可能自我不是第二套目标表；不再使用“超我”、马斯洛需要层次或罗杰斯实现倾向作为变量来源 |
| 能力与自我调节 | 领域能力、班杜拉领域自我效能、自我调节计划、自动应对反应；v0 暂定重评、情境修改、注意转移、暂停/边界 | 自我效能和自我调节共同归入此单元但保持语义区别；策略选择属于 CAPS，世界模型只执行下一轮注意提示并感知实际结果；不建独立调节或防御模块，四种策略进入原型评测后再判断是否调整 |
| 行为签名 | CAPS if-then 规律、共情力度与回应倾向 | 只保留一套条件行为机制；强化证据只作为更新条件，特质激活只作理论标签；共情力度是每轮派生量 |

## 1.3 已确定的排除项

- **大五 OCEAN**：只作外部评估坐标，不进入人格内核，也不反向驱动任何状态或行为；
- **艾森克 PEN**：从运行时与外部评估中删除，仅保留历史研究说明；
- **Gray RST（BAS/BIS/FFFS）**：属于早期未经用户确认而加入的补充候选，现已从当前架构删除，不建立对应字段或替代 PEN；
- **本我—自我—超我**：不作为人格实体、变量或三层仲裁器；冲动、价值约束和调节功能直接进入 CAPS；
- **阿德勒理论**：外移为历史解释，不提供运行变量；原有差距、目标、效能和行动功能由 Markus 与 CAPS 处理；
- **马斯洛整套理论**：只作外部评估，不建立需要层次、满足度、衰减、驱动力或自我实现状态；
- **罗杰斯实现倾向**：从人格架构删除，不建立总成长驱力、目标函数或外部评估指标；
- **埃里克森八阶段**：不建立年龄阶段或关系阶段状态机；“亲密—孤独”只可作为外部关系评估主题；
- **机能充分发挥的人**：不作为人格变量、发展终点、目标函数或评测标准；
- **行为主义习惯变量**：不建立独立习惯状态；重复行为只由 CAPS 行为签名组织，强化证据作为更新条件，特质激活只作理论标签；
- **表达抑制机制**：不建立长期抑制偏好或专用触发器；表达层可以调节措辞强度，但不得伪造内部情绪和立场；
- **宽泛攻击性参数**：当前唯一来源是已删除的 PEN 精神质内容，不进入人格内核；若未来出现实际需求，必须重新定义具体机制和理论来源；
- **规则敏感性与敌意候选**：均为未经用户确认而加入的占位概念，已经删除；不创建字段、别名或替代理论包装；
- **16PF、HEXACO 等宽泛特质分类**：不进入人格内核；目前只保留大五这一套外部评估坐标。

## 1.4 一次交互的逻辑步骤

以下是逻辑依赖，不代表必须串行调用多个模型：

1. 世界模型把文本、语音、图像、时间等输入拟合成统一感知状态，并在确有用途时附加与观察分离的 Kelly 建构解释；
2. 检索层按当前情境取回少量相关记忆证据；
3. 若感知到明确求助、脆弱或安全威胁线索，调用规划器可按需启用外部依恋照料插件/Skill；普通互动直接跳过；
4. CAPS 编码当前事件及可选的外部能力建议，并激活相关预期、情绪、目标、价值和调节能力；
5. 同一套激活网络处理目标竞争、现实约束和价值约束，形成状态增量与行为倾向；需要共情时，同时给出受推断置信度、关系情境及澄音自身边界约束的本轮共情力度；
6. LLM 根据人格结果生成最终语言，表达系统映射动作、表情和 TTS；
7. 本轮事件与结果写入互动记忆，长期变化由后续学习机制审慎更新。

输入理解可以由小参数量 LLM、Encoder、规则或混合方式完成；CAPS 内部的激活计算是公式、规则网络、神经网络、潜空间还是混合方案，目前仍未确定。

## 1.5 数据归属

- `PersonalityState`：只保存归并后确认的权威状态和参数，采用一份统一结构；
- 慢变量：只是 `PersonalityState` 中某个可学习字段的更新属性和摘要估计，不是第三套记忆库；目前确定由互动记忆提供交互证据，知识图谱是否承担人格学习证据及其引用格式，延期到基于 llm-wiki 的知识图谱架构研究；
- EAS 气质：情绪性、活动性和社交性分别保留；它们共享理论来源但不共享定义、数值或更新路径；
- 知识图谱：继续保存身世、`born_at`、人物与实体关系等已确定事实；是否保存或索引人格更新证据暂不在本文决定；
- 互动记忆：保存原始交互事件及其来源、时间和上下文，作为当前已经确定的长期学习证据来源；
- Kelly 建构：由世界模型在感知解释阶段按需执行；观察和解释分离，项目不采用建构图，建构列表也不进入 `PersonalityState`；
- Markus 自我表示：只用一类 `self_representations` 容器；`current` 保存达到门槛的领域自我图式，`hoped/feared` 保存可能自我，工作自我概念即时派生；身份事实仍由知识图谱持有；
- 依恋：只持久化焦虑/回避两个连续维度；四种依恋类型按需派生，依恋来源的自我概括可进入关系领域自我图式，对他人的预期进入 CAPS，不持久化 `working_model`；
- 依恋照料系统：外移为按需触发的插件或 Skill，只提供能力建议，不直接写人格状态；
- 情绪：效价—唤醒是唯一可写连续内核；具体情绪和表达标签即时派生；
- 自我知识评估：按领域比较当前自我图式与相匹配证据，只生成按需或离线报告，不建立全局人格参数；
- 用户对 AI 的稳定接纳：原始行为写入互动记忆，长期模式只折叠为现有关系安全/被接纳预期，不另建 UPR 状态；
- 人格内核：读取相关证据，但不复制完整经历；
- 外部评估：大五、Bem 工具性/表达性与马斯洛视角读取跨情境行为样本生成报告，禁止回写人格内核；
- LLM：负责输入语义解析和最终表达，不作为唯一的人格存储。

AI 年龄只由身份事实 `born_at` 计算，表示“澄音诞生了多久”。它可以参与时间感知、自我叙事和纪念日，但不能自动推导心理成熟度或人类发展阶段。
