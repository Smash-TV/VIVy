### 2.3 特质流派

#### 2.3.1 情绪

##### 2.3.1.1 理论研究梳理

- **Watson & Tellegen（1985）情绪二维结构**：对情绪的因子分析反复得到两个**相互独立**的维度——**积极情感（Positive Affect, PA）** 与 **消极情感（Negative Affect, NA）**。注意：PA 与 NA 不是一根轴的两端，而是**两根独立的轴**——一个人可以同时高 PA 高 NA（情绪强烈）或都低（平静寡淡）。测量工具 **PANAS**（Positive and Negative Affect Schedule）即基于此。
- **Russell（1980）环形模型（Circumplex Model）**：情绪也可以用 **效价（valence）× 唤醒（arousal）** 两个维度描述，是另一个常用坐标系。
- **情绪强度（Affect Intensity）**：Larsen & Diener（1987）提出的**独立人格维度**——个体体验情绪的**整体强弱/振幅**，**不分积极或消极**。高情绪强度者对积极事件和消极事件都反应强烈，情绪峰值更高、**情绪变化幅度更大**（更容易大起大落）。它与"敏感性"是**正交的两个维度**，不能互相合并或折叠。
- **情绪敏感性（Affect Sensitivity）**：对积极情绪和消极情绪体验强度的**方向性差异**——积极与消极的敏感度可以分离（有人对好事敏感、对坏事钝感），这正是思维导图里"强积极情感／弱积极情感／强消极情感／弱消极情感"的来源。
- **情绪表达性（Emotional Expressiveness）**：情绪**外在表现**的多少（King & Emmons 的 EEQ，Gross 的研究）。Gross 的研究曾把表达抑制作为情绪调节策略测量，但本项目不实现独立抑制偏好或触发器；重评等调节策略归 CAPS 能力与调节计划，表达性只回答“愿意表现多少”。

> 对 AI 的意义：情绪系统需要"**感知强度**"和"**表达强度**"两个旋钮分开调。澄音可以"感知到强烈共情"（高敏感性）但"表达得克制优雅"（中低表达性），这才是记录员人设的味道。

##### 2.3.1.2 结构化架构设计

**权威情绪内核：效价—唤醒连续状态 + 已保留的强度、敏感性与表达性**：

> **当前决定**：采用 Russell 的效价—唤醒坐标作为唯一可写的连续情绪状态，也就是情绪内核。PA/NA 只允许作为外部分析或即时换算结果，PAD 不进入运行时；离散情绪名称和 TTS 标签均从连续状态与当前情境派生，不能反向覆盖内核。

> ⚠️ 以下 JSON 中的数值（如 `0.85`、`0.9`）为**示例值**，用于说明结构；实际配置值应通过量表测量或人设校准确定，并持久化到 `configs/personality_core.json`。

```json
{
  "affect": {
    "coordinate": "valence_arousal",
    "baseline": {"valence": 0.10, "arousal": 0.00},
    "state": {"valence": 0.10, "arousal": 0.00},
    "affect_intensity": 0.85,
    "sensitivity": {
      "pos_sensitivity": 0.9,
      "neg_sensitivity": 0.7
    },
    "expressivity": 0.6,
    "dynamics": {
      "decay_rate": 0.05
    }
  }
}
```

**连续状态的最小更新关系**：

```
世界模型提供事件与对象
        ↓
CAPS 评价事件意义，产生 valence_delta / arousal_delta 候选
        ↓
affect_intensity 调节总体变化振幅
pos_sensitivity / neg_sensitivity 按效价方向调节输入增益
        ↓
state 向 baseline 衰减并叠加本轮增量，经过饱和边界得到新坐标
        ↓
坐标 + 对象 + 责任归属/可控性等评价 → 本轮情绪名称与行动倾向
        ↓
expressivity 与表达约束 → 语言、动作和 TTS
```

- `valence` 表示总体愉快—不愉快，`arousal` 表示激活—低激活；具体范围、零点、衰减和更新函数仍需通过工程评测确定，上述数值不是最终尺度；
- **连续坐标不等于完整情绪**：愤怒和恐惧都可能是负效价、高唤醒，仍须由对象、威胁、责任归属、可控性和行动倾向区分；
- **情绪强度是独立维度**：`affect_intensity` 管"整体振幅/激烈程度"（高强度者情绪强烈、波动幅度大），`pos_sensitivity`/`neg_sensitivity` 管"积极-消极方向的不对称"——两者正交，不能互相替换；四分类（强/弱积极 × 强/弱消极）仅由方向敏感度推导；
- **强度 ≠ 外在表达**：`affect_intensity` 管**内心体验的振幅**（大起大落），`expressivity` 管**外在表现多少**——高强度的澄音内心翻涌，但可以表达克制；
- 表达性低时：情绪仍会积累，外部动作、TTS 和措辞强度可以降低，但不能把真实立场或情绪状态伪造为 `neutral`；
- 高频用户互动时必须有饱和边界，避免状态无限累积；
- PA/NA、PAD、具体情绪名称和现有 7 个 CosyVoice 标签都只读取或换算同一份效价—唤醒状态，不建立第二份可写情绪状态。

**接入点**：
- 直接对接 `emotion.py` 与 SKILL.md 的【情绪输出规则】——把"按对话氛围选情绪"从提示词规则升级为状态计算+规则；
- TTS 语气：`emotion` 标签已由 CosyVoice 消费，无需改动。

#### 2.3.2 大五人格（Big Five / OCEAN）

##### 2.3.2.1 理论研究梳理

- 提出者：Costa & McCrae（NEO-PI-R 量表体系）；词源学路线由 Goldberg 发展（Big Five）。
- 核心：人格可用五个宽泛维度描述，每个维度下分 **6 个 facet（子特质）**，共 **30 个子特质**：
  - **开放性 O（Openness）**：想象、审美、情感、行动、观念、价值（想象力丰富 / 审美敏感 / 情感丰富 / 求新 / 思辨 / 价值观开放）；
  - **尽责性 C（Conscientiousness）**：胜任、秩序、尽责、追求成就、自律、审慎；
  - **外向性 E（Extraversion）**：热情、乐群、果断、活跃、寻求刺激、积极情绪；
  - **宜人性 A（Agreeableness）**：信任、坦诚、利他、顺从、谦逊、同理心；
  - **神经质 N（Neuroticism）**：焦虑、抑郁、自我意识、冲动、脆弱等负性反应倾向。
- 与已有模型的关系：E 与 N 在测量上与艾森克 PEN 的同名维度高度对应，但 PEN 已从本项目人格架构删除；这种相关性只用于解释量表历史，不能成为数据回写路径。EAS 情绪性、活动性和社交性已经分别保留；它们不能自动映射成大五分数。

> 对 AI 的价值：大五可作为**外部评估坐标**，用统一词汇观察澄音在一段时间内呈现出的宽泛行为倾向。它只描述运行结果，不解释人格如何生成，也不承担跨模块参数复用。

##### 2.3.2.2 项目中的使用边界（已确定）

大五不写入人格内核，不作为人格变量。它与人格内核之间是严格单向关系：

```text
人格内核运行状态 + 一段时间内的跨情境行为样本
                        ↓
                  大五外部评估
                        ↓
              OCEAN 评估报告与诊断说明
```

- `PersonalityState` 与 `configs/personality_core.json` 中禁止设置 OCEAN 字段；
- OCEAN 分数不能作为情绪、主动聊天、关系、需要、回复风格或行为选择的输入；
- OCEAN 分数不能用于生成或覆盖 SKILL.md 中的人设；
- 评估应优先依据多个情境中的可观测行为，而不是让 LLM 一次自评后把结果当作人格事实；
- 评估报告可以用于开发诊断、版本对比和一致性测试，但不得自动回写人格内核；
- 具体投影方法要等《7_理论变量归并表》确定权威变量后再设计。

**接入点**：未来独立的评估工具或离线测试流程；不接入人格运行管线。
