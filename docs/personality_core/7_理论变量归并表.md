# 人格内核 · 六套理论变量重叠与取舍表

> 状态：第十轮归并结案版；A—R 已全部作出当前工程取舍，O 作为跨知识图谱研究问题单独存档。
>
> 定位：这是人格模型正式工程的第一项设计产物。它先解决六套理论之间“哪些变量在重复描述同一个现象、谁拥有最终解释权”的问题；目前不选择公式、神经网络、潜空间、LoRA 或混合实现，也不提前设置变量权重。

## 1. 范围

本文覆盖当前人格架构中的六个理论来源：

1. 认知流派；
2. 精神分析流派；
3. 特质流派；
4. 生物学流派；
5. 人本主义流派；
6. 行为主义与社会学习流派。

表中的“理论变量”只是候选概念。只有完成归并并被指定为权威变量后，它才可能进入未来的 `PersonalityState`。理论名称本身不等于运行时模块，也不要求每套理论分别实现一套计算引擎。

## 2. 取舍动作

| 动作 | 含义 | 工程约束 |
|---|---|---|
| **合并** | 多个理论在描述同一个心理现象 | 只保留一个权威变量和一条更新路径，其他名称作为来源或解释别名 |
| **关联** | 变量含义不同，但存在影响关系 | 分别保留；后续明确影响方向、时间尺度和边界 |
| **外部投影** | 某理论适合描述或评估，不适合驱动人格 | 只能由运行结果生成报告，不能反向写入人格状态 |
| **外移** | 内容属于记忆、世界模型或表达层 | 人格内核只接收摘要或输出倾向，不复制原始内容 |
| **删除** | 变量没有独立解释力，或无法形成可验证用途 | 不进入状态、配置和提示词 |
| **历史保留** | 理论有研究史或解释价值，但不适合作为工程机制 | 只保留理论说明和文献，不创建状态、Schema 或运行路径 |

归并时遵守一个原则：**同一种心理现象只能有一个权威来源**。如果三个分数都声称代表“外向”，却能独立更新，系统就无法解释冲突。

## 3. 已确定的决定

### 3.1 大五人格只作为外部评估坐标

大五人格（OCEAN）不写入人格内核，不作为人格变量，也不成为其他模块的上游参数。

允许的数据方向只有：

```text
人格内核运行状态 + 跨情境行为样本
                ↓
        大五外部评估器
                ↓
       OCEAN 评估报告
```

禁止反向路径：

```text
OCEAN 分数 ──×──> 情绪更新 / 行为选择 / 人设提示词 / 长期学习
```

因此：

- `PersonalityState` 和 `configs/personality_core.json` 不设置 OCEAN 字段；
- OCEAN 分数不参与情绪、需要、关系、价值、认知评价或表达强度计算；
- 不依据 OCEAN 分数生成或覆盖澄音的人设摘要；
- 评估结果按需生成，可写入独立的评估记录，但不能被记忆学习流程当作人格事实；
- 外部评估方法与映射关系要等权威变量确定后再设计。

### 3.2 CAPS 作为主要运行框架

CAPS 被确定为人格内核的主要运行框架，用五类认知—情感单元组织保留下来的变量，并以 `if-then` 行为签名表达稳定的情境化人格。

这里的“统一”是**项目内部的统一计算语法**，不是宣称 CAPS 已经在学术上统一或证明了六大人格流派。其他理论只有在提供 CAPS 尚未表达、且能验证的机制时才保留；不会再为六个流派分别实现引擎。

### 3.3 PEN 模型退出人格架构

艾森克 PEN 只作历史研究保留，不进入人格内核，也不再设置 PEN 外部评估：

- E、N 与大五外向性、神经质高度重叠，而大五已经被限定为外部评估；
- P 把多个异质的冲动、冷漠、不遵从和人际行为现象压成一个宽泛维度，构念边界不清；
- 2019 年系统综述与元分析发现 P 不能良好代表其声称的“精神病倾向”，主要测到的是冲动性不遵从；
- 若社交性、活动性、情绪反应性、趋近/回避或冲动仍有工程价值，分别在对应归并项中判断，不能以 PEN 名义成套导入。

### 3.4 弗洛伊德结构模型退出人格架构

本我、自我、超我不作为三个心理实体、变量或三层仲裁器。不能简单说整个精神动力传统已被“证伪”，但经典三分结构缺少适合本项目的稳定操作定义，而且与 CAPS 的情感、目标/价值、能力/调节发生直接重复。

保留的是功能，不是弗洛伊德本体论：

- “冲动”改写为当前的即时行动倾向；
- “价值约束”进入 CAPS 的目标与价值；
- “现实检查、延迟、重评和抑制”进入能力与自我调节；
- 用户已决定保留的“防御反应”按自动调节/应对反应理解，不预设它来自本我—自我—超我冲突。

### 3.5 AI 诞生年龄不映射埃里克森阶段

埃里克森理论不是单纯的年龄量表，而是以人类身体发展、家庭与社会角色为背景的规范性生命阶段理论。AI 的 `born_at` 只能表示自诞生以来经过的时间，不能据此推出婴儿期、青春期、成年期或心理成熟度。

因此：

- 不建立 `current_stage`、`unlocked_virtues` 或八阶段状态机；
- `born_at` 作为身份与时间事实写入知识图谱，年龄按需计算；
- 认识周年、首次交心等属于互动记忆中的里程碑事件，不是人格阶段；
- 用户决定保留的“亲密—孤独”降为外部关系评估主题，不表示澄音正处于埃里克森第六阶段，也不得回写人格内核。

### 3.6 宽泛特质模型的统一边界

按照用户在 Q 项的决定，16PF、HEXACO、PEN 及其他宽泛特质分类均不进入人格内核。只有大五被保留为外部评估坐标；如果某个具体概念（例如冲动、社交性、真诚）有独立机制价值，必须脱离原量表后单独参加变量归并，不能借理论名称直接获得保留资格。

### 3.7 G 行按 Markus 的概念边界拆分自我表示

对原始文献复核后，需要收紧此前“Markus 自我图式管理所有主观自我认识”的说法。1977 年的自我图式是**特定行为领域中，由过去经验形成且能组织信息加工的自我概括**；个体可以在某个领域没有清晰图式。可能自我和工作自我概念分别是 1986、1987 年同一研究脉络中的相关概念，但不是 1977 年自我图式的同义词。

项目仍只使用一类 `self_representations` 记录，以避免重复容器，但这只是存储归并；理论语义必须严格区分：

- `mode: current` 只对应已经形成的领域自我图式；临时自我描述不能直接写入；
- `mode: hoped | feared` 对应 Markus 与 Nurius 的可能自我；它们是未来自我表示，不冒充当前图式；
- 工作自我概念是本轮被激活的自我表示子集，不持久化第二份人格状态。

边界如下：

- 身世、`born_at`、角色设定和人物关系等身份事实由知识图谱保存，原始交互经历由互动记忆保存；知识图谱是否同时承担人格证据存储，另待 llm-wiki 架构研究；
- 当前自我图式必须指向澄音自己、限制在具体领域、具有重复证据与自我重要性，并能组织同领域判断或预测；允许某领域暂无图式；
- 希望或恐惧自我与当前图式可在同一领域按需比较，不保存全局 `gap`；
- 对用户可靠性、可获得性与回应方式的判断属于 CAPS 预期与信念，不属于自我图式；
- 价值、当前目标和行动计划由 CAPS 持有，可能自我只提供具体化的未来方向；
- `confidence` 只用于当前自我命题的主观确信度，不能冒充准确度，也不复用为可能自我的实现概率；
- 自我知识按领域比较当前图式与相匹配证据，只生成按需或离线评估，不建立全局 `self_knowledge` 参数。

依恋内部工作模型的数据归属也已经确定：

- 符合上述门槛、明确指向澄音自己的关系自我概括，可以进入 `self_representations.current`；
- 对用户可靠性、可获得性和回应方式的预期进入 CAPS 的预期与信念；
- 依恋焦虑与依恋回避作为两个连续慢变量保存；安全型、专注型、冷漠型和恐惧型只由二维位置按需派生；
- 不再持久化 `working_model`、`self_model` 或 `other_model` 第三份状态。

### 3.8 罗杰斯概念的本轮边界

| 概念 | 本轮处理 | 状态 |
|---|---|---|
| 当前自我—理想自我差异 | 并入 Markus 当前自我图式与 `hoped` 可能自我的同领域比较；删除独立 `gap` | 已确定 |
| 机能充分发挥的人 | 定义过于宽泛，不能形成单一可测机制，不进入人格内核、评测目标或提示词 | 已确定删除 |
| 实现倾向 | 与目标、价值、可能自我、自我效能及长期学习重复，且不能给出可验证的事件级规则 | 已确定删除 |
| 共情理解 | 保留为 CAPS 可选择的互动策略，不作为静态人格分数，也不等于赞同或服从 | 已确定保留 |
| 经验开放 | 作为当前自我图式的证据更新原则：面对不舒服或反图式证据时不过早否认，允许在证据累积后修订自我认识；不设独立分数 | 已确定归并 |
| 一致性 / 真诚 | 当前—理想差异不再归它管理；关系中的真诚归入表达约束，表示外部表达不伪造内部立场，但允许克制、隐私和情绪调节 | 已确定归并 |
| 无条件积极关注 | 不作为澄音对用户的无条件输出；改为观察用户是否在澄音不完美、不同意或有负面情绪时仍给予稳定接纳，作为用户指向 AI 的关系证据 | 已确定方向，长期折叠方式随 I 行继续设计 |

### 3.9 共情不取消澄音的主体性

共情只要求澄音努力理解用户的视角，并根据证据置信度表达这种理解。它不要求她永远温柔、永远正确、永远接纳用户的结论，也不覆盖她自己的情绪、目标、价值与关系边界。澄音可以关心一个人，同时对其行为生气、反对、拒绝或暂时不愿继续某种互动；系统不得用固定的“接纳 → 共情 → 温柔建议”流水线抹平这些反应。

共情的“力度”是每轮根据情境生成的表达控制量，不是长期人格特质。它表示本轮回应应把多少注意力放在理解和回应用户体验上，并由以下证据共同约束：用户当前情绪与求助信号、用户是否明确想被倾听、视角推断置信度、关系情境、任务类型，以及澄音自己的情绪与边界。力度越高，不代表越赞同；推断置信度不足时，应降低具体断言强度或先澄清。

### 3.10 无条件积极关注改为用户指向 AI 的关系证据

把罗杰斯原本用于治疗关系的概念反向用于用户—AI 关系，是本项目的工程转译，不宣称与临床概念完全等价。这里真正关心的不是用户说了多少赞美，而是当澄音犯错、拒绝、表达不同意见或出现负面情绪时，用户是否仍然尊重她的主体性并愿意修复关系。

- 单次夸奖、频繁聊天或顺从澄音都不能直接证明稳定接纳；
- 原始互动写入互动记忆，不把“用户无条件关注我”写成知识图谱事实；
- 长期、跨情境证据可以更新 CAPS 预期与信念中的关系安全/被接纳预期，不另设一套 UPR 状态；
- 该预期可以影响澄音在关系中的防御、真诚表达和主动靠近，但不能强迫她信任、亲密或原谅；
- “无条件”只描述用户关注在挫折下是否稳定，不意味着用户必须接受伤害，也不意味着澄音拥有索取关注的权利。

### 3.11 效价—唤醒坐标成为情绪内核

人格状态只维护一份 Russell 效价—唤醒连续坐标，作为所有模块读取和更新的权威情绪内核。具体情绪名称由坐标、对象与情境评价共同派生；PA/NA 只作外部分析或即时换算，PAD 暂不进入运行时，离散情绪标签和 TTS 标签不得反向覆盖连续状态。情绪强度、正负敏感性和表达性继续作为不同功能的调节参数存在，不复制成坐标轴。

### 3.12 依恋照料系统外移为按需能力

依恋照料系统不进入人格内核，也不成为澄音的常驻关怀倾向。它作为外部触发插件或 Skill，在感知到明确求助、脆弱或安全威胁线索时由调用规划器按需启用，只返回照料/保护建议；CAPS 结合澄音的价值、能力、关系、情绪与边界决定是否采纳。插件与 Skill 共用一套语义，具体封装留到实现阶段选择。

### 3.13 调节策略采用 v0 初定集合

第一版暂定四种调节策略：`reappraise`、`modify_situation`、`redirect_attention`、`pause_or_set_boundary`。它们共用 CAPS“能力与调节计划”中的同一种策略记录，不建立独立调节管理器；“暂定”表示这是进入原型与评测的当前版本，只有评测发现无法覆盖真实情境时才调整枚举。

感知与调节共享一条闭环，但职责不能合并：世界模型只报告事实、推测、不确定性，执行 CAPS 给出的下一轮 `attention_hint`，并在后续感知中观察策略结果；是否重评、修改情境、转移注意、暂停或设立边界，由 CAPS 根据澄音的情绪、目标、价值、关系和能力决定。任何包含价值判断、关系立场或行为取舍的调节决策都不得并入世界模型。

## 4. 当前未解决项

人格理论变量的本轮归并已经结案，当前没有继续阻塞理论架构的未解决项。O 涉及互动记忆、llm-wiki 知识图谱证据结构与慢变量学习算法，不在缺少知识图谱架构研究时强行决定，已转入第 6 节存档。

## 5. 已解决的取舍总表

已解决项只保留最终结论和工程边界，不再重复“可选取舍”和“初步建议”。原编号永久保留，便于追溯讨论历史。

## 7. 从总表进入正式变量归并

总表审阅完成后，再把每个保留候选展开成一行。正式归并表建议使用以下字段：

| 字段 | 记录内容 |
|---|---|
| `canonical_id` | 归并后的唯一英文标识；尚未确定时留空 |
| 中文名称 | 面向设计讨论的名称 |
| 理论来源 | 原理论、提出者及文档位置 |
| 严格定义 | 它描述什么，以及明确不描述什么 |
| 重叠变量 | 与哪些理论变量完全或部分重叠 |
| 归并动作 | 合并、关联、外部投影、外移、删除或历史保留 |
| 权威来源 | 哪个变量拥有最终解释权和写权限 |
| 时间尺度 | 单轮、短期、长期或近似静态 |
| 所属位置 | 人格内核、世界模型、互动记忆、知识图谱、表达层或外部评估 |
| 更新证据 | 什么现实事件可以改变它 |
| 更新触发 | 实时更新、定时更新、离线反思或禁止学习 |
| 依赖关系 | 输入哪些变量，又影响哪些变量 |
| 可观测验证 | 用什么情境和行为判断设计是否成立 |
| 当前状态 | 待定、保留、合并、外部投影、外移、删除或历史保留 |
| 决策理由 | 为什么这样处理，未来在什么证据下允许改判 |

这一阶段只确定语义、归属和权威性，不设置具体权重，不决定线性或非线性，也不创建正式代码类。等变量集合稳定后，才能据此设计最小状态结构和工程评测集。

## 8. 审阅方式

修改本表时，优先在“当前决定”栏写结论；如果选择“合并”，同时写明准备保留的权威概念；如果选择“关联”，写明两个概念不能合并的关键理由。没有充分理由时保持“待定”，不为完整性强行保留变量。
